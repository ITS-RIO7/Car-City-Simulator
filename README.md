# Car City Simulator

Arcade drift racing through a neon city. This branch is the Flutter port of the
Kotlin/Compose game that lives on `main`. The original
sources are still here (under `app/`, untouched) so nothing is lost while the
port is validated.

## What was ported

| Kotlin original | Flutter port |
| --- | --- |
| `GameMode` (3 modes) | `lib/models.dart` — Drift Attack, Tandem Circuit, Freestyle Practice |
| `CameraMode` (5 cams) | `lib/models.dart` + `DriftSim._updateCamera` — chase, hood, drone, bumper, action |
| `Car` (6 cars, tuning maths) | `lib/models.dart` — same stats, same upgrade formulas |
| `Track` (4 circuits) | `lib/data/tracks_data.dart` — **generated from the Kotlin source**, centre lines, boundaries, clipping points, descriptions copied verbatim |
| `DriftPhysicsEngine` | `lib/game/sim.dart` — same constants (car 54×28, grip 7.5, yaw 4.2, drift threshold 14°) |
| `DriftScoringSystem` | `lib/game/sim.dart` — drift points, 1.6 s combo window, x20 cap, apex bonus |
| `GameStorage` | `lib/services/storage.dart` — coins, unlocks, upgrades, records, settings |
| Main menu / garage / track select / records / settings / game | `lib/screens/` |
| HUD, mini map, pause + result dialogs | `lib/screens/game_screen.dart` |

## Not ported yet

- **Engine audio** — `DriftAudioSynth.kt` (procedural engine note) has no Flutter
  equivalent yet; the settings toggle is stored but silent.
- **Per-track city props** — the Kotlin tracks carry hand-placed buildings,
  lamps and skybridges with sign text. The port generates an equivalent neon
  skyline ring around each circuit instead of using those exact placements.
- **Rooftop / mid-facade sign text** — the generated skyline uses neon bands,
  not text.

## Run it

```
flutter pub get
flutter run
```

Landscape only. The `android/` folder is generated by CI, so a fresh clone needs
`flutter create . --platforms=android` once if you want to build locally.

## APK

Push to `flutter-port`, or run the *Build APK* workflow manually. A `v*` tag also
publishes the APK to a GitHub Release.
